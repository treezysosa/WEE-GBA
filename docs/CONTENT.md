# Content and presets

Schema 2 `.wee` files use a JUCE ValueTree XML root `WEE schema="2"`. The 14 `PARAM` children contain actual-unit values for gain, attack, decay, sustain, release, cutoff, waveform, source (0 oscillator / 1 sample), root (MIDI note), sampleStart, sampleEnd (0–1), loop (0/1), keyLow and keyHigh (MIDI notes). Each ID must occur exactly once. Nonfinite/out-of-range values, fractional integer controls, invalid trim/key ranges, duplicates and unknown schemas are rejected. Schema 1's seven synthesis parameters migrate to schema 2 with sampler defaults and no sample path. A saved invalid trim/key configuration is rejected on reload; correct the controls before saving.

Sample references are root properties: `samplePath` is an absolute host-state/fallback path; file presets also store `sampleRelative`, relative to their preset directory. When loading a file preset, an existing relative file takes priority. If no absolute fallback exists, a missing relative path is retained as the requested absolute path so that the loader can report the missing asset. Host state never requires filesystem reads to resolve a relative preset location. It queues decoding and remains silent until prepared content is adopted at an audio block boundary. Manual recovery uses LOAD SAMPLE / RELOCATE and then saving the patch again. Audio is not embedded in state.

`Content/manifest.json` records two original CC0 synthetic demos, generated reproducibly by scripts/generate-demo.py; CI regenerates and verifies SHA-256, channel count, sample rate and provenance fields. WAVs are build/package artifacts rather than checked-in binaries. The files are not vocal recordings or a commercial library. The original generator uses integer oscillators; it contains no scraped media or cloned voices. See Samples/LICENSE.txt.

The loader supports JUCE's WAV, AIFF and FLAC decoders and keeps assets outside the plugin binary. It decodes mono/stereo assets up to 120 seconds and 128 MiB into stereo float RAM. Failure replaces current content with an empty asset and clears the preview. New requests supersede older work. This phase provides native file browsing and sample audition through MIDI/on-screen keys, not a metadata-search index or a multisample library manager.

Future recordings must include creator, source, license, usage rights, hash, language/region and consent where relevant. Accurate region/language metadata needs knowledgeable review. The synthetic demos use `zxx` (no linguistic content) and no assigned region. There is no vocal collection in this release.
